# Dynamic Pose Drawing Drills

Three short figure-drawing exercises for studying movement, depth, and weight. Each drill gives you a timed plan, a few things to observe, and a way to review your sketch. You can use the linked pose references or substitute your own images.

| Drill | What you will practice | References |
| --- | --- | --- |
| [Gesture and momentum](01-gesture-and-momentum.md) | Whole-body direction and clear silhouettes | A leap and a running turn |
| [Foreshortening](02-foreshortening.md) | Near and far forms, overlap, and scale | Two reaching poses |
| [Balance and support](03-balance-and-support.md) | Ground contacts and the body's weight | Kneeling and four-point support |

## How to use the drills

1. Open a drill and choose one linked reference. Set a timer to **30 seconds**. Draw the large direction and masses first.
2. Make a **2-minute** study of the same image. Add the structural relationships named in the drill.
3. Hide the reference. Write one thing you preserved and one thing you would change. Use the [practice log](practice-log.md) to compare sessions over time.

The linked references are on [DynamicPoses.art](https://dynamicposes.art/), where you can also open a pose and use its built-in 30-second, 1-minute, 2-minute, or untimed practice option. The written exercises here work with any timer.

## About this repository

This is a public practice guide for artists. It contains instructions and links to references. The DynamicPoses.art website application and image files are not part of this repository.

If an exercise is unclear or a reference link stops working, open an issue with the drill name and the step that needs attention.
